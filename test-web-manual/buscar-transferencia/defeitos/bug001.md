# 🐞 Defeito

Baseado na ISO-29119-3 e em ferramentas de gestão de defeitos.

| Campo                        | Detalhes                                                                 |
| ---------------------------- | ------------------------------------------------------------------------ |
| ID                           | BUG001                                                                   |
| Título                       | Paginação apresenta inconsistência visual em diferentes resoluções de tela |
| Testador                     | Lúcia de Melo                                                           |
| Data e Hora                  | 28/05/2026                                                              |
| Resultado Esperado           | A paginação deve manter consistência visual em qualquer resolução de tela, sem desalinhamento ou quebra de layout. |
| Resultado Atual              | Ao alterar a resolução da tela, os botões de paginação apresentam desalinhamento e inconsistência visual. |
| Evidências                   | Adicionar screenshot em: `evidencias/       |
| Prioridade                   | Média                                                                    |
| Severidade                   | Média                                                                    |
| Informações sobre o Software | Aplicação Banco Web — ambiente local — navegador Chrome                |
| Rastreabilidade              | Sessão exploratória da funcionalidade Buscar Transferências            |
| Status                       | Aberto                                                                   |

---

# ▶️ Passos para Reprodução

1. Acessar a funcionalidade Buscar Transferências.
2. Visualizar a listagem com paginação.
3. Reduzir ou alterar a resolução da tela.
4. Observar o comportamento dos botões de paginação.
