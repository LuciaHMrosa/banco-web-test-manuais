# 🐞 Defeito

Baseado na ISO-29119-3 e em ferramentas de gestão de defeitos.

| Campo                        | Detalhes |
|----------------------------|----------|
| ID                         | BUG004 |
| Título                     | Campo de token permite entrada de caracteres sem limite de tamanho |
| Testador                   | Lúcia de Melo |
| Data e Hora                | 28/05/2026 |
| Resultado Esperado         | O campo de token deve possuir limite de tamanho compatível com o padrão de autenticação definido pelo sistema. |
| Resultado Atual            | O campo aceita entrada de tokens extremamente longos sem validação ou bloqueio. |
| Evidências                 | `evidencias/bug004.png` |
| Prioridade                 | Média |
| Severidade                 | Baixa |
| Informações sobre o Software | Banco Web — ambiente local — Chrome |
 Rastreabilidade            | Sessão exploratória — Transferências |
| Status                     | Aberto |
