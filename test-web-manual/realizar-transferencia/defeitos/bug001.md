# 🐞 Defeito

Baseado na ISO-29119-3 e em ferramentas de gestão de defeitos.

| Campo                        | Detalhes |
|----------------------------|----------|
| ID                         | BUG001 |
| Título                     | Sistema exige autenticação para transferência no valor exato de R$5.000,00 |
| Testador                   | Lúcia de Melo |
| Data e Hora                | 28/05/2026 |
| Resultado Esperado         | Transferências acima de R$5.000,00 devem exigir token de autenticação (exclusivamente valores > 5000). Transferência no valor de R$5.000,00 deve ser realizada sem token. |
| Resultado Atual            | O sistema exige autenticação também para transferências no valor exato de R$5.000,00, bloqueando a operação sem token. |
| Evidências                 | `evidencias/bug001.png` (print da tentativa de transferência com valor 5000) |
| Prioridade                 | Alta |
| Severidade                 | Média |
| Informações sobre o Software | Aplicação Banco Web — ambiente local — navegador Chrome |
| Rastreabilidade            | CT001 — Realizar transferência com valores válidos - Gherkin |
| Status                     | Aberto |

---

# ▶️ Passos para Reprodução

1. Acessar a página de transferência.
2. Informar valor **R$5.000,00**.
3. Selecionar conta origem ativa com saldo suficiente.
4. Selecionar conta destino ativa.
5. Não informar token.
6. Clicar em “Transferir”.

| Campo | Valor |
|------|------|
| Valor | 5.000,00 |

| Conta origem | Ativa com saldo suficiente |
| Conta destino | Ativa |
