# 🐞 Defeito

Baseado na ISO-29119-3 e em ferramentas de gestão de defeitos.

| Campo                        | Detalhes |
|----------------------------|----------|
| ID                         | BUG002 |
| Título                     | Saldo das contas não é atualizado automaticamente após transferência |
| Testador                   | Lúcia de Melo |
| Data e Hora                | 28/05/2026 |
| Resultado Esperado         | Após a realização de uma transferência, os saldos das contas origem e destino devem ser atualizados imediatamente na interface. |
| Resultado Atual            | Os saldos só são atualizados após atualização manual da página. |
| Evidências                 | `evidencias/bug002_1.png`, `evidencias/bug002_2.png` e `evidencias/bug002_3.png` |
| Prioridade                 | Média |
| Severidade                 | Média |
| Informações sobre o Software | Banco Web — ambiente local — Chrome |
| Rastreabilidade            | Sessão exploratória — Transferências |
| Status                     | Aberto |

---

# ▶️ Passos para Reprodução

1. Acessar tela de transferência  
2. Realizar uma transferência válida  
3. Observar saldo das contas na interface  
4. Não atualizar a página
