# 🐞 Defeito

Baseado na ISO-29119-3 e em ferramentas de gestão de defeitos.

| Campo                        | Detalhes                                                                                             |
| ---------------------------- | ---------------------------------------------------------------------------------------------------- |
| ID                           | BUG003                                                                                               |
| Título                       | Campos de login permitem inserção excessiva de caracteres                                            |
| Testador                     | Lúcia de Melo                                                                                        |
| Data e Hora                  | 28/05/2026                                                                                           |
| Resultado Esperado           | Os campos de usuário e senha devem possuir limite máximo de caracteres definido pelo sistema.        |
| Resultado Atual              | Os campos permitem inserção superior a 1.000 caracteres sem qualquer bloqueio ou validação aparente. |
| Evidências                   |  `evidencias/bug003.png`                                                   |
| Prioridade                   | Baixa                                                                                                |
| Severidade                   | Baixa                                                                                                |
| Informações sobre o Software | Aplicação Banco Web — ambiente local — navegador Chrome                                              |
| Rastreabilidade              | Sessão exploratória da funcionalidade Login                                                          |
| Status                       | Aberto                                                                                               |

---

# ▶️ Passos para Reprodução

1. Acessar a tela de login.
2. Inserir texto com mais de 1.000 caracteres no campo usuário ou senha.
3. Observar comportamento do campo.

---

# 📥 Dados Utilizados

| Campo   | Valor                              |
| ------- | ---------------------------------- |
| Usuário | Texto com mais de 1.000 caracteres |
| Senha   | Texto com mais de 1.000 caracteres |
